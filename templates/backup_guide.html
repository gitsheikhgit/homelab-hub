  2. Go to Compute → Instances.
  3. Click the blue Create Instance button.

Part 2: Configure the Oracle Cloud VM to Receive Backups

Now we configure the cloud VM to securely store encrypted backups over SSH / SFTP or via the lightweight restic-rest-server.

💻
Which Terminal to Open: Open Terminal on your Mac/PC and SSH into your new Oracle Cloud VM: ssh -i /path/to/private.key ubuntu@<ORACLE_PUBLIC_IP>

Step 2.1: Update & Create the Backup Storage Folder

Terminal: Oracle Cloud VM 
sudo apt update && sudo apt upgrade -y
sudo mkdir -p /var/backups/restic
sudo chown -R ubuntu:ubuntu /var/backups/restic
sudo chmod 700 /var/backups/restic
df -h /  # Verify you have ~190+ GB available

Step 2.2: (Optional & Recommended) Run Restic REST Server with Docker

The Restic REST server is ultra-fast, supports append-only ransomware protection, and uses minimal RAM (~15 MB):

Terminal: Oracle Cloud VM 
# 1. Install Docker on the Oracle VM
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker ubuntu

# 2. Run Restic REST Server with secure authentication
docker run -d \
  --name restic-rest-server \
  --restart always \
  -p 8000:8000 \
  -e OPTIONS="--private-repos --append-only" \
  -v /var/backups/restic:/data \
  restic/rest-server:latest

# 3. Create backup user & password on the server
docker exec -it restic-rest-server create_user backupuser MySuperSecurePassword123

Part 3: Client Server Setup (Any Machine You Want to Backup)

Run these steps on ANY server, VM, or computer that you want to back up to your Oracle 200GB drive (e.g. this homelab server, Proxmox VE 1, Proxmox VE 2, or your Mac).

💻
Which Terminal to Open: Open Terminal on the machine being backed up (e.g. ssh user@192.168.1.100).

Step 3.1: Install Restic on Client

Terminal: Client Machine 
# On Debian / Ubuntu:
sudo apt update && sudo apt install -y restic

# On Mac (via Homebrew):
brew install restic

Step 3.2: Configure Client Credentials & Encryption Key

File: /etc/restic/backup.env 
sudo mkdir -p /etc/restic
sudo chmod 700 /etc/restic

# 1. Create your secret 48-char encryption key
echo "" | sudo tee /etc/restic/password
sudo chmod 600 /etc/restic/password

# 2. Create the backup environment file (Using REST Server or S3)
sudo bash -c 'cat > /etc/restic/backup.env << "EOF"
# If using Oracle 200GB VM REST Server:
RESTIC_REPOSITORY="rest:http://backupuser:MySuperSecurePassword123@:8000/cloud-server"

# Or if using Oracle Object Storage S3:
# RESTIC_REPOSITORY="s3:https://.compat.objectstorage..oraclecloud.com/"
# AWS_ACCESS_KEY_ID=""
# AWS_SECRET_ACCESS_KEY=""

RESTIC_PASSWORD_FILE="/etc/restic/password"
EOF'

sudo chmod 600 /etc/restic/backup.env
🔑 S3-Compatible Object Storage Credentials (Optional)
  • • Namespace: Found under Tenancy Details (e.g. your-tenancy-namespace)
  • • Customer Secret Key: Profile > User Settings > Customer Secret Keys > Generate Secret Key
  • • Access Key: The generated Access Key ID
  • • Secret Key: The generated secret key string (copy and save immediately)
📷 Visual Guide: Finding your Object Storage Namespace & Customer Secret Keys (Access Key & Secret Key) in Oracle Cloud Console

Step 3.3: Initialize the Repository on Client

Terminal: Client Machine 
sudo bash -c 'set -a; source /etc/restic/backup.env; set +a; restic init'

Part 4: Complete Shell Scripts Reference

Here are the complete production-grade shell scripts to save in your backup folder:

Script: /usr/local/bin/backup-to-oracle.sh

/usr/local/bin/backup-to-oracle.sh (chmod +x) 
#!/bin/bash
# ==============================================================================
# Automated Encrypted Homelab Backup Script
# ==============================================================================
set -e

# Load credentials
if [ -f /etc/restic/backup.env ]; then
    set -a
    source /etc/restic/backup.env
    set +a
elif [ -f /etc/restic/oracle.env ]; then
    set -a
    source /etc/restic/oracle.env
    set +a
else
    echo "[-] Error: Credentials file not found in /etc/restic/!" >&2
    exit 1
fi

echo "===================================================================="
echo "[*] Starting Encrypted Cloud Backup to Oracle..."
echo "[*] Timestamp: $(date -u)"
echo "===================================================================="

# 1. Run Restic Backup with compression and smart exclusions
restic backup \
    --verbose \
    --compression auto \
    --exclude-caches \
    --exclude "$HOME/.cache" \
    --exclude "$HOME/.gemini" \
    --exclude "$HOME/scratch" \
    --exclude "$HOME/.antigravity-ide" \
    --exclude "**/.trash" \
    --exclude "**/lost+found" \
    --exclude "**/node_modules" \
    --exclude "**/*.tmp" \
    --exclude "/mnt/storage/ollama_data" \
    --exclude "/mnt/storage/vaultwarden_data" \
    --exclude "/mnt/pool/immich/thumbs" \
    --exclude "/mnt/pool/immich/encoded-video" \
    /etc \
    /var/lib/casaos/apps \
    /DATA/AppData \
    "$HOME" \
    /mnt/storage/docuseal \
    /mnt/storage/docuseal_data \
    /mnt/storage/papra_data \
    /mnt/storage/papra_ingest \
    /mnt/storage/nextcloud_data \
    /mnt/storage/Music \
    /mnt/pool/immich/upload \
    /mnt/pool/immich/library \
    /mnt/pool/immich/backups \
    /mnt/WDDATA/Photos \
    /mnt/WDDATA/iPhone \
    /mnt/WDDATA/"Pixel 8" \
    /mnt/WDDATA/"Rizwana iPhone" 2>/dev/null || true

echo ""
echo "[*] Applying Retention Policy & Pruning Old Snapshots..."

# 2. Retain 7 daily, 4 weekly, 12 monthly snapshots
restic forget \
    --keep-daily 7 \
    --keep-weekly 4 \
    --keep-monthly 12 \
    --prune

echo ""
echo "[+] Backup Complete! Snapshot Summary:"
restic snapshots --compact
echo "===================================================================="

Part 5: Automated Daily Systemd Timer Setup

Create these two systemd files to automate daily execution at 02:30 AM:

1. /etc/systemd/system/restic-backup.service 
[Unit]
Description=Automated Encrypted Homelab Backup to Oracle Cloud
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/backup-to-oracle.sh
StandardOutput=journal
StandardError=journal
Nice=15
IOSchedulingClass=2
IOSchedulingPriority=7

[Install]
WantedBy=multi-user.target
2. /etc/systemd/system/restic-backup.timer 
[Unit]
Description=Daily Automated Encrypted Backup to Oracle Cloud
RefuseManualStart=no
RefuseManualStop=no

[Timer]
# Runs daily at 02:30 AM local time with 15min randomized delay
OnCalendar=*-*-* 02:30:00
RandomizedDelaySec=900
Persistent=true

[Install]
WantedBy=timers.target
Terminal Commands to Activate 
sudo systemctl daemon-reload
sudo systemctl enable --now restic-backup.timer
sudo systemctl list-timers | grep restic

Part 7: Complete Disaster Recovery & Restore

If your server hardware completely dies or you get a brand new drive:

Disaster Recovery Commands (Fresh Ubuntu Install) 
# 1. Install Restic
sudo apt update && sudo apt install -y restic

# 2. Re-create credentials
sudo mkdir -p /etc/restic
echo "" | sudo tee /etc/restic/password
sudo chmod 600 /etc/restic/password

# 3. View available restore points
sudo bash -c 'set -a; source /etc/restic/oracle.env; set +a; restic snapshots'

# 4. Restore everything to the root filesystem
sudo bash -c 'set -a; source /etc/restic/oracle.env; set +a; restic restore latest --target /'

# 5. Restart Docker containers
sudo systemctl restart docker
